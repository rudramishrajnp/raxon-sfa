# User Manuals

## 1. MR (Medical Representative) Manual
**Daily Workflow:**
- **Sync**: Open the app with an internet connection to sync master data.
- **Punch In**: Start the day by capturing selfie and GPS location.
- **Work Plan (MTP)**: Submit Tour Plan (MTP) by the 25th of the month.
- **Daily Call Report (DCR)**: Perform check-in and check-out at Doctor/Chemist locations. 
- **Expenses**: Submit daily expenses (TA/DA/Misc) and attach bill images.
- **Punch Out**: End the day. Offline data will sync automatically in the background.

## 2. Area/Regional Manager (AM/RM) Manual
**Managerial Duties:**
- **Dashboard**: Track real-time team location and route history on the map.
- **Approvals**: Approve or reject MTP submissions and Daily Expenses.
- **Overrides**: Approve Attendance/GPS overrides requested by MRs.
- **Team Activity**: View productive vs. non-productive calls of subordinates.

## 3. Admin Panel Manual
**Operational Control:**
- **Master Data**: Manage Doctor, Chemist, Product, and Pricing masters.
- **Geofencing**: Manage customer coordinates.
- **Analytics**: View Sales, Expense, and Attendance dashboards.
- **Reports**: Generate and schedule automated email reports.
- **Audit**: View system audit logs and login histories.

## 4. Super Admin Panel Manual
**Master Control:**
- **Company Management**: Create and configure Multi-Company environments.
- **Dynamic RBAC**: Create custom roles and configure granular permissions.
- **Feature Toggles**: Turn specific modules ON/OFF or make them Mandatory/Optional.
- **Global Settings**: Configure Timezones, Currencies, and System Configurations.
- **Database Backups**: Trigger manual backups or restore historical backups.
