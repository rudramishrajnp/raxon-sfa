# Raxon Project Roadmap

## Version 1.1 (Next Quarter)
- **Gamification:** Add leaderboards for Secondary Sales and target achievements.
- **Advanced Route Optimization:** Integrate Google Maps Directions API to suggest the most efficient daily route for MRs.
- **e-Detailing (Interactive Presentations):** Allow MRs to show PDF/Video presentations to Doctors from within the app, logging time spent per slide.

## Version 2.0 (Next Year)
- **AI-Powered Insights:** Implement machine learning to predict Doctor availability, prescribe optimal visit frequencies, and detect anomalies in expense reports.
- **Multi-Tenant SaaS Architecture:** Upgrade backend database architecture from Single-Tenant to Multi-Tenant (Schema-per-tenant or Row-Level Security) to support multiple independent pharmaceutical clients on the same infrastructure.
