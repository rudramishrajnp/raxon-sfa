# User Acceptance Testing (UAT) Checklist

## Client Sign-Off Areas

### General Usage
- [ ] App installs smoothly on target devices (Android/iOS).
- [ ] UI is responsive and legible across device sizes.
- [ ] Navigation is intuitive for all user roles.

### Functional Roles
- [ ] **MR Role:** Can complete a full day (Punch In -> MTP -> DCR -> Expense -> Punch Out) seamlessly.
- [ ] **Manager Role:** Can review team activity and approve requests without delays.
- [ ] **Admin Role:** Can access Enterprise Analytics and generate accurate CSV/PDF reports.
- [ ] **Super Admin:** Can manage companies, roles, and global settings.

### Edge Cases
- [ ] App handles low network / 2G speeds gracefully without crashing.
- [ ] App successfully queues data when completely offline.
- [ ] GPS spoofing attempts are blocked or flagged.
- [ ] Time/Date tampering attempts are blocked.
